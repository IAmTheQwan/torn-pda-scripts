# torn-pda-scripts

## Fast Trade

`theqwan-fast-trade.user.js` provides a PDA-friendly colored trade control. A
short tap performs only the currently displayed manual action; a three-second
hold opens local target and wallet-reserve settings. It can open a configured
player's trade, fill and submit the visible Add Money form, and use Torn's
visible acceptance controls without background Torn requests or chained server
actions. See [FAST-TRADE.md](FAST-TRADE.md) for installation and state details.
