TORN API DISCLOSURE

How the history importer uses data

Data storageFinished-auction equipment data is stored persistently in the owner's private Cloudflare D1 database.
Data sharingOnly the owner can view the dashboard. Data is not sold or shared with another service.
PurposePersonal auction-price research, historical comparisons, and trend analysis.
Key handlingA custom public-level key limited to market → auctionhouse is stored only as an encrypted Worker secret and is never returned to the browser.
